## 快速搜索

`Cmd/Ctrl + O` 按项目名打开笔记；全文搜索可以组合下面的条件。

| 想找什么 | 搜索条件 / 入口 |
| --- | --- |
| 高优先级项目 | `tag:#高优先级` |
| 待升级工程 | `tag:#需要升级` · [[01-导航与索引/项目维护#升级计划\|查看进度]] |
| TPM 项目 | `tag:#TPM系列` |
| 后端与数据 | `path:10-后端与数据项目` |
| 某个接口或命令 | 搜索完整接口路径、`npm run` 或 `mvn` |
| 最近修改、日记、待建档系统 | [[01-导航与索引/项目维护\|项目维护]] |

新增项目可通过 `Cmd/Ctrl + P` → **QuickAdd: 新建项目文档**。笔记放入对应项目目录后，自动统计和折叠列表会同步收录；再在本页补一行用途说明。模板见 [[templates/项目模板\|项目模板]]，维护方法见 [[08-知识库指南/维护计划/知识库更新计划\|知识库更新计划]]。
