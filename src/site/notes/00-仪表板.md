## 快速操作

### 今天要做什么？

**启动项目：**
1. 找到项目：使用上面的列表或搜索
2. 查看快速启动卡片
3. 复制启动命令

**记录问题（QuickAdd 已接通）：**
1. 按 `Cmd/Ctrl + P` → 搜索 **QuickAdd: 记一笔问题**
2. 依次填写：项目名 / 问题简述 / 描述 / 解决方案 / 分类
3. 自动追加到 [[问题记录\|问题记录]] 的「问题列表」

**写日记 / 建项目（QuickAdd + Templater）：**
- `Cmd/Ctrl + P` → **QuickAdd: 今日日记**（或点 Calendar 日期）
- `Cmd/Ctrl + P` → **QuickAdd: 新建项目文档** → 选平台 → 自动套模板

**查找历史问题：**
1. 打开 [[问题记录\|问题记录]]
2. 搜索关键词
