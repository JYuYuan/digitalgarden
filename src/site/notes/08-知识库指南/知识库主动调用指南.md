## 推荐入口

```mermaid
flowchart LR
    A["定位任务"] --> B["查项目与历史记录"]
    B --> C["核对源码"]
    C --> D["执行与验证"]
    D --> E["更新文档"]
```

日常项目查询从 [[01-导航与索引/项目总览\|项目导航]] 进入；跨系统关系用 [[01-导航与索引/项目关系图\|项目关系图]]，升级和待核实信息用 [[01-导航与索引/项目维护\|项目维护]]。这些是查阅约定，具体执行取决于助手能访问的文件与工具。

## 项目事实源优先级

当信息冲突时按以下顺序判定：

| 优先级 | 事实源 |
| --- | --- |
| 1 | 真实项目文件：`package.json`、`build.gradle`、`versions.gradle` |
| 2 | 单项目文档 |
| 3 | 汇总索引页 |
| 4 | 页面中的自动查询结果 |

汇总页只应派生事实，不应覆盖真实项目依赖。

## 问题记录流程

现有脚本的安装与完整用法见 [[scripts/README\|知识库工具脚本]]。快速记录示例：

```bash
kb-add "问题描述" "解决方案"
```

记录后检查：

- 项目标签是否正确；`kb-add` 未识别的项目会写为 `unknown-project`，需按实际项目修正。
- 是否能通过全文搜索定位。
- 是否包含复现条件与验证结果，以及是否需要补充到对应项目页的常见问题。
- 管道采集的原始输出是否已整理；它不是自动生成的解决方案。

记录入口是 [[09-问题与记录/问题记录\|问题记录]]；可复用的处理方法整理到 [[09-问题与记录/常见问题解决方案\|常见问题解决方案]]。
