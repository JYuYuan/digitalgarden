## 新增项目时的检查顺序

```mermaid
flowchart LR
    A["核对源码"] --> B["建立项目页"]
    B --> C["补导航与关联"]
    C --> D["检查统计与链接"]
```

1. **建档**：用 [[templates/新建项目文档\|新建项目文档]] 选择对应目录与平台，记录实际技术栈、启动条件和源码入口。
2. **补入口**：更新 [[01-导航与索引/项目总览\|项目导航]]；首页只保留常用入口及分类快照。
3. **补关联**：涉及跨项目接口或数据加工时，更新 [[01-导航与索引/项目关系图\|项目关系图]] 与 [[01-导航与索引/项目总览#技术栈\|技术栈]]。
4. **核对**：确认项目总览的目录统计包含新页，并检查内部链接；文件属性可从 [[08-知识库指南/维护计划/文件总览.base|文件总览]] 查看。
