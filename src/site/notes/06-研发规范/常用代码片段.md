## React Hooks

### useState 基础用法

放在函数组件或自定义 Hook 的顶层；`User` 使用项目已有类型。

```typescript
import { useState } from 'react';

const [count, setCount] = useState(0);
const [user, setUser] = useState<User | null>(null);
const [list, setList] = useState<string[]>([]);

// 函数式更新
setCount(prev => prev + 1);
```

### useEffect 常见场景

`fetchData`、`loadUserData` 为业务函数占位。按实际闭包引用声明依赖；计时器的清理函数在 effect 重跑或组件卸载时执行。

```typescript
import { useEffect } from 'react';

// 组件挂载时执行
useEffect(() => {
  fetchData();
}, []);

// 依赖更新时执行
useEffect(() => {
  if (userId) {
    loadUserData(userId);
  }
}, [userId]);

// 清理副作用
useEffect(() => {
  const timer = setInterval(() => {}, 1000);
  return () => clearInterval(timer);
}, []);
```

### 自定义 Hook

演示手动调用 `run` 时的加载、数据与错误状态。它不会自动发起请求，也没有取消或并发覆盖保护；失败后再次成功不会清除已有 `error`。项目已有请求 Hook 时优先沿用，复制此例前补齐所需行为。

> [!example]- 展开代码示例 · typescript
> ```typescript
> // useRequest.ts
> import { useState, useCallback } from 'react';
>
> function useRequest<T>(api: () => Promise<T>) {
>   const [data, setData] = useState<T | null>(null);
>   const [loading, setLoading] = useState(false);
>   const [error, setError] = useState<Error | null>(null);
>
>   const run = useCallback(async () => {
>     setLoading(true);
>     try {
>       const result = await api();
>       setData(result);
>     } catch (err) {
>       setError(err as Error);
>     } finally {
>       setLoading(false);
>     }
>   }, [api]);
>
>   return { data, loading, error, run };
> }
>
> export default useRequest;
> ```

## Ant Design 常用组件

### ProTable 基础配置

适用于已使用 Pro Components 的项目。补齐 `DataType`、`handleEdit` 和 `fetchList`；示例直接返回 `success: true`，实际接入需先按接口结果判断成功状态，并映射列表及总数。

> [!example]- 展开代码示例 · tsx
> ```tsx
> import { ProTable } from '@ant-design/pro-components';
>
> <ProTable<DataType>
>   columns={[
>     { title: '姓名', dataIndex: 'name', key: 'name' },
>     { title: '年龄', dataIndex: 'age', key: 'age' },
>     {
>       title: '操作',
>       key: 'action',
>       render: (_, record) => (
>         <a onClick={() => handleEdit(record)}>编辑</a>
>       )
>     }
>   ]}
>   request={async (params) => {
>     const res = await fetchList(params);
>     return { data: res.data, success: true, total: res.total };
>   }}
>   rowKey="id"
>   search={{ labelWidth: 'auto' }}
>   pagination={{ pageSize: 10 }}
> />
> ```

### ProForm 表单

补齐 `saveData` 与 `message` 的来源。保存失败时由已有请求层或提交逻辑处理错误，成功提示应在确认业务成功后显示。

```tsx
import { ProForm, ProFormText } from '@ant-design/pro-components';

<ProForm
  onFinish={async (values) => {
    await saveData(values);
    message.success('保存成功');
  }}
>
  <ProFormText
    name="name"
    label="姓名"
    rules={[{ required: true }]}
  />
  <ProFormText
    name="email"
    label="邮箱"
    rules={[{ required: true, type: 'email' }]}
  />
</ProForm>
```

## API 请求封装

### Axios 封装

展示浏览器请求与响应拦截器。沿用项目实际环境变量、鉴权和错误提示约定；这里读取 `process.env.API_BASE_URL`，不同构建工具的变量注入方式需单独核对。

响应拦截器返回 `response.data`，调用方接收的是响应体；业务错误码、令牌刷新和 Axios 类型声明需按项目已有实现处理。

> [!example]- 展开代码示例 · typescript
> ```typescript
> // utils/request.ts
> import axios from 'axios';
> import { message } from 'antd';
>
> const request = axios.create({
>   baseURL: process.env.API_BASE_URL,
>   timeout: 10000
> });
>
> // 请求拦截器
> request.interceptors.request.use(
>   config => {
>     const token = localStorage.getItem('token');
>     if (token) {
>       config.headers.Authorization = `Bearer ${token}`;
>     }
>     return config;
>   },
>   error => Promise.reject(error)
> );
>
> // 响应拦截器
> request.interceptors.response.use(
>   response => response.data,
>   error => {
>     message.error(error.message || '请求失败');
>     return Promise.reject(error);
>   }
> );
>
> export default request;
> ```

### API 调用

请求地址与存储键是占位值。`success` 回调不等于业务成功，应按接口检查 HTTP 状态和业务返回值；`fail` 分支负责请求失败提示。

```javascript
// 网络请求
wx.request({
  url: 'https://api.example.com/data',
  method: 'POST',
  data: { id: 1 },
  success: (res) => {
    console.log(res.data);
  },
  fail: (err) => {
    wx.showToast({ title: '请求失败', icon: 'none' });
  }
});

// 本地存储
wx.setStorageSync('key', 'value');
const value = wx.getStorageSync('key');
```
